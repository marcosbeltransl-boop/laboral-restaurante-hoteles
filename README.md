# Uniformes Pro — Landing page (estática)

## Cómo abrir
1. Descomprime el ZIP.
2. Abre `index.html` en tu navegador (doble clic).

## Imágenes (todas separadas para que las sustituyas)
Están en `assets/images/`:

- `hero.jpg` (fondo del hero)
- `mockup.png` (imagen del mockup)
- `product-chef.jpg`
- `product-apron.jpg`
- `product-shirt.jpg`
- `product-hotel.jpg`
- `about.jpg` (foto del bloque “¿Por qué elegirnos?”)
- `avatar-laura.png` (avatar del testimonio destacado)
- `testimonial-1.jpg`
- `testimonial-2.jpg`
- `testimonial-3.jpg`
- `contact.jpg` (imagen del bloque de contacto)

Puedes reemplazarlas manteniendo el mismo nombre, o cambiar las rutas en `index.html`.

## Personalización rápida
- Colores: edita `:root` en `styles.css`
- Textos: `index.html`
- Envío del formulario: reemplaza el comportamiento demo en `script.js` por tu API.
